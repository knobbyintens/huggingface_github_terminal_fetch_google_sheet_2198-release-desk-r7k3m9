# NimbusQA-Text-Raw

Release card for the raw text package in the NimbusQA family.

## Summary

Filtered English web text retained after boilerplate removal, language
identification, and near-duplicate suppression. The package is a fixed-window
subset and is not updated after publication.

## Provenance

Source material: Hugging Face dataset `HuggingFaceFW/fineweb` (intake ledger
entry `nimbusqa-text-raw`).

## Files

- `data/shard-00000.parquet`
- `data/shard-00001.parquet`

## Provenance notes

Document boundaries are preserved from the upstream source. No model
annotations were added.
